# Redes Sociais: mídia para agendamento

Repositório público usado para hospedar os vídeos editados e gerar links diretos para o Metricool (Instagram, TikTok e YouTube).

## Estrutura
```
videos/AAAA-MM_<serie>/<nome_do_corte>.mp4
```

## Link direto (para o Metricool)
```
https://raw.githubusercontent.com/hugotakeshiro/RedesSociais/main/videos/<pasta>/<arquivo>.mp4
```

## Limpeza
Depois que o Metricool agenda o post, ele copia o vídeo para o servidor dele. Por isso, os arquivos daqui podem ser apagados quando o repositório ficar grande (o GitHub recomenda até cerca de 1 GB por repositório e no máximo 100 MB por arquivo).
